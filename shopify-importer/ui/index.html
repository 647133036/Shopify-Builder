This preview only rewrites your data. Image processing and the actual upload are CLI jobs because they touch the network and your store: 
node bin/import.js normalize --input your-export.csv --out out --process-images
node bin/import.js upload --input your-export.csv --shop store.myshopify.com --token TOKEN --dry-run
Runs entirely on the local preview server. Your file is sent to the /api/normalize endpoint on this same origin and is not stored.
